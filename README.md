# E-Commerce Backend

A complete E-Commerce Backend built using Node.js, Express.js, MongoDB and JWT Authentication.

## Features

- User Registration & Login
- JWT Authentication
- Admin Authentication
- Product CRUD
- Product Search
- Product Filter
- Pagination & Sorting
- Shopping Cart
- Wishlist
- Address Management
- Product Reviews
- Coupon System
- Order Management
- Payment Management
- Cloudinary Image Upload
- Error Handling
- ObjectId Validation

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Cloudinary
- Multer
